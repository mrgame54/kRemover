## A deep-cleaning uninstaller for Fedora (DNF-based Distros)

**kRemover** is a deep-cleaning uninstaller built for modern Fedora desktops. Package managers like DNF safely remove system files but they intentionally leave behind personal user data and configuration files. 
kRemover allows you to easily locate and safely trash leftover user files in a native, easy-to-use interface.
*(Note: kRemover is designed exclusively for native system RPMs. Sandboxed formats like Flatpak or Snap are not supported yet.)*

### 📦 Technologies
* `Python`
* `PySide6 (Qt6)`
* `FreeDesktop.org XDG`
* `Polkit`
* `send2trash`

---
### Features
* **Deep Data Cleaning for RPMs:** Automatically scans standard XDG directories (`~/.config`, `~/.local/share`, `~/.cache`) for leftover app data left behind by native RPM packages.

* **Simple UI:** A clean, native interface that lists installed applications alongside their official system theme icons.

* **Safe Deletion (Trash):** Moves leftover data to the system Trash instead of permanent deletion, ensuring you can always restore files if a mistake is made.

* **Integrated Uninstaller:** Uses Polkit to securely prompt for your sudo password and execute `dnf remove` command without opening a terminal.
  
* **Accurate Size Calculation:** Dynamically calculates and displays precise file and folder sizes (B, KB, MB, GB).

---
### 🛠️ Dependencies
Make sure following Dependencies are installed:

**Runtime Dependencies (Automatically installed via RPM):**
- `python3`
- `python3-pyside6` (Cross-platform GUI framework)
- `python3-send2trash` (FreeDesktop Trash specification hook)
- `polkit` (Standard Linux privilege escalation for DNF)

**Build Dependencies:**
- `rpm-build`
- `rpmdevtools`

---

### 🚀 Installation

**Option 1: Install via RPM (Recommended)**
1. Download the latest `.rpm` installer from the [**Releases**]() page.
2. Install it via DNF:
```bash
sudo dnf install ./kremover-0.9.0-1.fc44.noarch.rpm
```
**Option 2: Compile from Source**
If you prefer to build the RPM package yourself from scratch, please refer to the Build Instructions.

--- 
### 🐧 Supported Platform
kRemover is officially developed for and supported on **Fedora KDE Plasma 44**. 
kRemover should also run on any **DNF-based distribution** (including standard Fedora GNOME, RHEL, AlmaLinux, and Rocky Linux)
